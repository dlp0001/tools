# tools

Проект по аренде инструментов.

Статус: старт. Стек ещё не выбран, каркас намеренно пустой — код, зависимости
и структура появятся, когда определится продукт.

## Что дальше

1. Описать продукт и сценарии в [docs/idea.md](docs/idea.md).
2. Выбрать стек (веб, мобайл, бэкенд) и завести каталог `src/`.
3. Добавить инструкции для сборки и запуска в этот README.

## Локальная разработка

Пока нечего запускать. Репозиторий содержит только документацию.
