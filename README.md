# tools

Аренда инструментов в Израиле. Рабочее название бренда — «Аренда Перфораторовна».

Собственный парк инструмента, аренда понедельно с пятницы по пятницу,
доставка и возврат курьером по центру страны.

## Документация

- [docs/business-process.md](docs/business-process.md) — актуальный бизнес-процесс:
  недельный такт, клиентский путь, состав админки, прайс, подписка, зоны доставки.
- [docs/idea.md](docs/idea.md) — продукт, каталог, экономика на три года.
  Часть решений там помечена как устаревшая, актуальные лежат в бизнес-процессе.

## Прототип

[prototype/index.html](prototype/index.html) — кликабельный прототип в одном файле,
без сборки и зависимостей. Откройте его в браузере.

Что внутри:

- **Витрина.** Наборы и отдельные единицы, календарь свободных пятниц, выбор зоны,
  подписка, расходники, живой расчёт прогрессии и залога.
- **Чекаут.** Контакты с подтверждением телефона и проверкой контрольной цифры
  теудат зеут, адрес и окно доставки, договор с прайс-листом поломок, оплата.
  Оформленная бронь появляется в админке.
- **Админка.** Метрики недели, маршрут на пятницу, календарь экземпляров,
  брони, каталог, редактор прайса и прайс-лист поломок.

Прайс в админке редактируемый: поменяйте число, и витрина с бронями пересчитаются.
Данные живут в памяти страницы, перезагрузка возвращает исходный набор.
